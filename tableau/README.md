# Tableau workbook

> Synthetic data from a seeded generator. Not real company, customer or financial results.

**Status: published and checked.** Tableau Public URL: https://public.tableau.com/app/profile/vijay.chamakuri/viz/SaaSRevenueIntelligenceMRRRetentionBillingControls/Executiveoverview

The workbook opens in Tableau Public 2026.2.2 with no errors, all four dashboards were inspected at 1366 x 768, every KPI tile ties to `expected_kpis.csv`, and screenshots from Tableau are in `screenshots/`.

| File | Purpose |
|---|---|
| `workbook/saas_revenue_intelligence.twbx` | Four dashboards at 1366 x 768, one Hyper extract per data source. Generated by `make tableau` from the governed marts. |
| `data/*.csv` | The extracts packaged into the workbook: aggregates, synthetic IDs, no personal fields. |
| `workbook_manifest.yml` | Title, data sources, worksheets, dashboards, actions (generated). |
| `expected_kpis.csv`, `validation_evidence.csv` | Expected KPI values by month and their tie-out to the packaged extract (generated). |
| `calculated_fields.md`, `field_dictionary.md` | Parameters, calculated fields and field definitions (generated). |
| `qa_checklist.md` | Manual checks with version, tester, date and result. |

Dashboards: **Executive overview** (KPI tiles, MRR bridge for a chosen month, ending MRR trend, what-changed callout), **Revenue and retention** (movement by month, GRR and NRR trend, segment, plan, channel and year filters, cohort logo retention), **Customer risk** (risk distribution, lift by decile, threshold parameter with precision, recall and queue size, synthetic action queue), **Finance controls** (invoice and payment tie-out, variance, failed-payment exposure, exception classes with drill-through to invoices, control status and freshness).

To change a view, edit `src/tableau/build.py` and rerun; the `.twbx` is regenerated. Publishing: [docs/tableau_public_release.md](../docs/tableau_public_release.md).
